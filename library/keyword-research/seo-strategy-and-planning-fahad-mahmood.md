# SEO Strategy and Planning

## Overview

A robust SEO strategy aligns technical architecture, search intent taxonomy, structured data, and content velocity to build search engine authority.

---

## Autonomous Agent Workflow

```
1. Discovery & Audit
   ├── Analyze target audience (Commercial vs Informational searchers)
   ├── Identify primary competitors & ranking keywords
   └── Check technical stack (SSR, SSG, or SPA hydration requirements)
         │
2. Keyword Clustering & Taxonomy
   ├── Cluster by Search Intent (Commercial, Transactional, Navigational)
   ├── Map Programmatic Matrix (Entity × Location × Specialty)
   └── Establish Canonical URL rules & route patterns
         │
3. Implementation Phasing
   ├── Phase 1: Foundations (Semantic HTML, Meta architecture, Robots/Sitemaps)
   ├── Phase 2: Knowledge Graph (Schema.org JSON-LD, Dynamic OG cards)
   ├── Phase 3: Crawl Acceleration (IndexNow engine, XML sitemaps V2)
   ├── Phase 4: Intent Arbitrage (Colloquial & localized query aliases)
   └── Phase 5: Authority & Digital PR (Industry benchmark reports, embed badges)
```

---

- [ ] Strategic SEO roadmap documented in `docs/seo/seo-roadmap.md`.
- [ ] Keyword intent matrix and programmatic URL structure finalized.
- [ ] Multi-phase task breakdown created with assigned verification criteria.
