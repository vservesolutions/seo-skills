# Competitor and SERP Gap Analysis

## Overview

Competitor & SERP gap analysis reverse-engineers what is currently ranking on Google's Page 1 and finds unexploited opportunities where competitors have weak or outdated content.

---

## Analysis Framework

### 1. SERP Feature Opportunity Matrix
Identify which SERP features are present for target query clusters:
- **Local 3-Pack Maps**: Requires `LocalBusiness` schema + Google Business Profile.
- **Video Carousels**: Requires `VideoObject` Schema.org graphs + YouTube embeds.
- **Direct Answer Box (Featured Snippet)**: Requires 40-60 word definitive direct answer paragraphs.
- **Review Star Snippets**: Requires `AggregateRating` schema.
