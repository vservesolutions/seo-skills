# SEO Technical Auditor
Establish the crawl scope, environment, representative templates, baseline dates, and access to Search Console/server logs.
## Decisions
- Reconcile HTTP status, robots directives, canonical targets, rendered content, redirects, internal links, and sitemap URLs.
- Test representative URLs from each template and identify page-wide versus site-wide failures.
- Keep field traffic data, lab performance, and indexing observations separate. Missing data is not zero.
## Acceptance
Attach affected URLs, the observation source, reproducible checks, severity, owner, and expected validation window. Publishing robots, canonicals, redirects, or content requires the requested change scope.
