# SEO Task Execution and Auditing

## Overview

Auditing and pre-launch verification ensure that no broken tags, schema errors, or missing metadata reach production.

---

## 10-Point Pre-Launch SEO Checklist

1. [ ] **Title Tag**: Unique per page, 50–60 characters.
2. [ ] **Meta Description**: Unique, 140–155 characters, includes primary keyword and CTA.
3. [ ] **Canonical URL**: `<link rel="canonical" href="...">` present on all routes.
4. [ ] **OpenGraph / Twitter Tags**: `og:title`, `og:description`, `og:image` (1200x630), `twitter:card`.
5. [ ] **Heading Structure**: Exactly one `<h1>`, logical `<h2>` and `<h3>` nesting.
6. [ ] **Schema.org Structured Data**: Validated with 0 errors on Google Rich Results Test.
7. [ ] **Images**: Explicit `width`/`height`, `loading="lazy"`, descriptive `alt` tags.
8. [ ] **Robots.txt**: Accessible at `/robots.txt` referencing valid sitemaps.
9. [ ] **Sitemap.xml**: All canonical URLs listed with `<lastmod>` timestamps.
10. [ ] **Core Web Vitals**: Lighthouse Performance score > 90.
