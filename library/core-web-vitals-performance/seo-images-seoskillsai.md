# Visual Semantic Image Optimization Standard

Audits image delivery, responsive sizing, and metadata compliance for Google Images and Google Discover.

---

## 🖼️ Image Technical Standards

1. **Modern Format Compression:** Convert raster images to **WebP** or **AVIF** with $\ge$ 80% compression savings.
2. **Explicit Dimensions:** Always define `width` and `height` attributes on `<img>` tags to eliminate Cumulative Layout Shift (CLS).
3. **Google Discover High-Res Standard:** Featured thumbnails must be at least **1200px wide** with a **16:9 aspect ratio**.
4. **IPTC AI Metadata Labeling:** AI-generated images must include the IPTC `DigitalSourceType` attribute `trainedAlgorithmicMedia` to comply with Google digital provenance standards.
