# Topical Semantic Holistic Semantic SEO Content Standard

This skill establishes the Standard Operating Procedure (SOP) for crafting high-ranking, topical authority-rich content according to the **Holistic Semantic SEO Framework**.

---

## 🏛️ The 5 Semantic Pillars

1. **Entity-Attribute-Value (EAV) Modeling:**
   - Define the Central Entity, Primary Attributes, and Contextual Values before drafting.
   - Establish semantic triples (Subject -> Predicate -> Object) to feed knowledge graphs.

2. **Centerpiece Annotation (Above the Fold):**
   - The primary functional element (interactive tool, calculator, answer box, or key insight) **must render in the top 350px viewport** without requiring scrolling.
   - Never push centerpieces down with filler introductions or generic hero graphics.

3. **Anti-Thin Educational Prose Architecture:**
   - Every interactive or tool page MUST render **800+ words of structured educational body prose** beneath the interactive zone.
   - Required Structure:
     - `<h2>Understanding {Core Entity}</h2>` (Nuanced definition, clinical/technical context).
     - `<h2>The Theoretical & Engineering Framework</h2>` (Authoritative backing).
     - `<h2>Key Attributes, Implementation Steps & Checklist</h2>` (Scannable checklist).
     - `<h2>Frequently Asked Questions</h2>` (PAA-grounded, schema-tagged).

4. **Directional Internal Linking (Conduit Mesh):**
   - **Outer Nodes -> Silo Hub -> Core Flagship Pillar**: Pass link equity systematically upwards and horizontally across twin topic clusters.
   - **3x Anchor Diversity Rule**: Exact-match keyword anchor text must NEVER appear more than 3 times sitewide. Always use natural semantic variations.

5. **Modality Matching:**
   - Match the search query's verb modality in paragraph 1 (How-To -> numbered steps; Comparison -> evaluation matrix; Question -> direct bold answer).
