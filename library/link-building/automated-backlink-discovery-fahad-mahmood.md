# Automated Backlink Discovery

## Overview

This skill provides the reasoning heuristics and query syntax for an AI agent with web search capabilities to discover high-authority backlink opportunities, resource page inclusions, and competitor backlink gaps.

---

## 4-Step Autonomous Backlink Reconnaissance

```
1. SERP Footprint Discovery
   ├── Search: "top [niche] directory" OR "best [niche] platforms"
   ├── Search: inurl:resources "[niche]"
   └── Search: "[niche] list of tools" OR "[niche] software"
         │
2. Competitor Backlink Scraping
   ├── Search: link:[competitor1.com] OR "competitor1.com" -site:competitor1.com
   └── Identify listicles and directories ranking above the competitor
         │
3. Domain Authority & Relevance Filtering
   ├── Filter domains with DA > 30 and topical relevance
   └── Extract editorial contact details or submission forms
         │
4. Pitch Personalization
   └── Draft contextual, high-value addition requests
```

## Search Queries for AI Web Search Tools

```text
"best freelance video editor websites"
"top directories for creative agencies"
"hire video editors pakistan" inurl:resources
"video editing tools and directories" -site:pakiedit.com
```
